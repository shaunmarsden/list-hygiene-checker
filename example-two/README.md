# Worked Example Two: Shared Contact, Different People

The first [example](../example/) tests a confident duplicate, where shared identifiers and a name variant point the same way. This one tests the edge of that rule: two clearly different names sharing the same email and phone.

- [list.md](list.md): two different people sharing a household email and phone
- [output.md](output.md): the review, which rightly doesn't merge them
- [review.md](review.md): whether the reasoning held on a case built to look, on the surface, like a match for the first example's duplicate rule

The repository doesn't record which model wrote this output, or whether it knew what the test was checking. Read it as an illustration of what a good run looks like, not as a logged run.
