# List Hygiene Checklist

Use alongside a list export. Decide your required fields before scanning, not after.

## Required Fields for This List

- [ ] [Field 1, e.g. email]
- [ ] [Field 2, e.g. phone]

## Scan

- [ ] Every row checked for the required fields above
- [ ] Likely duplicates found, based on more than one shared identifier (not name alone)
- [ ] Possible duplicates kept visibly separate, flagged for a human check rather than merged
- [ ] Rows that are not real records (test entries, placeholders) flagged separately from incomplete real ones
- [ ] Staleness checked even on rows that look complete
- [ ] Genuinely clean rows called clean

## Before Acting on Anything

- [ ] Every suggested duplicate confirmed by someone who actually knows the list
- [ ] Nothing merged, deleted, or changed automatically
- [ ] Any staleness threshold used noted as illustrative, not a fixed rule
